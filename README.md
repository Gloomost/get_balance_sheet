## 🎯 背景与痛点

在利用大模型对上市公司进行短期偿债能力分析时，需从年报中提取**货币资金**、**流动负债合计**等指标，以计算现金比率、流动比率、速动比率。但在实际提取中，常见以下问题：

1. **指标干扰**：将"流动负债合计"与其他指标同时查询时，会导致所有指标识别出错；
2. **双表混淆**：年报中通常包含"合并资产负债表"和"母公司资产负债表"两张跨页表格，大模型难以区分，常将两张表数据混为一谈；
3. **年份错位**：表头两列年份顺序不统一（有的"今年"在前，有的"去年"在前），且部分表头使用 **"xx年1月1日"** 而非 **"xx年12月31日"**，导致模型无法正确对应数据。

本项目通过纯 Python 脚本对 PDF 表格进行定位、清洗与重组，实现了高准确率的资产负债表提取。

---

## ✨ 核心特性

- ✅ **智能定位**：自动识别并定位"合并资产负债表"，排除母公司表干扰
- ✅ **跨页合并**：自动处理跨页表格拼接，无需人工指定页码
- ✅ **年份校正**：自动识别"1月1日"等特殊表头，统一修正为"12月31日"，并按时间顺序排列（今年左、去年右）
- ✅ **附注兼容**：自动处理含"附注"列的表格格式
- ✅ **批量/单文件双模式**：支持遍历批量提取，也支持单文件快速调试
- ✅ **标准化输出**：输出为 Pandas DataFrame，并支持导出为 PDF

## 🚀 使用方法

项目提供两个主要函数：`batch`（批量）和 `one`（单文件）。

### 批量提取

```python
from extractor import batch

# 通过文件列表的下标控制提取范围
# 例如：提取第 0 到第 9 份年报
batch(start=0, last=10)
```

### 单文件提取

```python
from extractor import one

# 注意：Windows 路径分隔符请使用反斜杠 \\
one("C:\\Users\\Admin\\Downloads\\annual_report_2023.pdf")
```

## 🔧 技术实现

| 步骤 | 说明 | 关键设计 |
|:---|:---|:---|
| **Step 1** | 抽取 PDF 中所有表格文本，保存为嵌套列表 | 不直接判断跨页，因为不同公司页眉/页码格式不统一，难以截取 |
| **Step 2** | **定位资产负债表**：清洗表头后，若 `list[0] == "项目"`，且倒数第一、二个单元格模糊匹配 `"20" "年" "月" "日"`，则判定为合并资产负债表起点 | 只看倒数两列，避免第二列"附注"造成干扰；且因合并表总在母公司表之前，故优先定位到合并表 |
| **Step 3** | **确定终止位置**：从起点开始向后合并表格，直到某行模糊匹配 `"负债和所有者权益"`（资产负债表最后一行固定项目） | 利用固定项目作为截止符，兼容不同表述 |
| **Step 4** | **数据对齐**：以"项目名称"为中心合并前后空格作为项目名；其后非空字符串按位置填入年份列 | 若只有一个数值，判断其在剩余列表中的位置：位于前半段则填入"年份1"，后半段填入"年份2" |
| **Step 5** | **附注列处理**：若表格含"附注"列，其在列表中通常表现为空字符串，直接删除项目名称后的第一个空元素即可 | 此类表格格式通常较为规整 |
| **Step 6** | **格式统一**：转为 DataFrame 后，若表头含 `"1月1日"`，自动修正为上年 `"12月31日"`；随后比较两列日期，将**今年**置于左侧，**去年**置于右侧 | 此阶段才解决年份顺序问题，前期仅用"年份1/年份2"保持兼容 |
| **Step 7** | 保存为 PDF 格式 | - |

## ⚠️ 注意事项

1. **路径分隔符**：Windows 环境下输入文件路径时，文件名前的分隔符请使用反斜杠 `\\`。
2. **适用范围**：本项目**仅针对上市公司年报中的资产负债表**进行了特化优化，尚未实现对年报内其他表格（如利润表、现金流量表）或其他通用 PDF 跨页表格的一般化提取。
3. **输出说明**：当前版本默认提取的是**合并资产负债表**，母公司资产负债表不会被主动提取。
